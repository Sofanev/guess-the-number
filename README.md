# Угадай число

Веб-версия консольной игры на Python. Она запускается на одном компьютере, а играть в неё можно с любого устройства в вашей локальной сети.

## Запуск на компьютере-сервере

Нужен Python 3.10 или новее.

### 1. Установить зависимости

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Запустить веб-сервер

```bash
python app.py
```

После запуска игра будет доступна на самом компьютере по адресу:

```text
http://127.0.0.1:5000
```

Чтобы играть с другого устройства в той же Wi-Fi или локальной сети, узнайте локальный IP компьютера-сервера и откройте:

```text
http://ЛОКАЛЬНЫЙ_IP:5000
```

Например: `http://192.168.1.25:5000`.

## Если другие устройства не подключаются

- убедитесь, что устройства подключены к одной сети;
- разрешите Python входящие подключения в брандмауэре;
- проверьте, что порт `5000` не занят;
- не используйте `127.0.0.1` на другом устройстве — это адрес самого другого устройства.

Каждый браузер получает отдельную игру и собственный прогресс.

## Консольная версия

Старая версия игры по-прежнему запускается командой:

```bash
python game.py
```
