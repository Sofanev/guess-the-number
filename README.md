# NUM//HUNT

Ребрендинг классической игры «Угадай число» в браузерную аркаду для четырёх игроков.

## Возможности

- выбор игрока: Софья, Сергей, Мила или Настя;
- сохранение XP, побед, текущей и лучшей серии и числа попыток в SQLite;
- таблица лидеров общая для всех игроков этого сервера;
- история вариантов и подсказок в текущем раунде;
- три режима сектора, таймер, подсказки и адаптивный неоновый интерфейс.

Результаты хранятся на сервере в `instance/numhunt.sqlite3` и сохраняются после перезапуска приложения. У каждого браузера свой текущий игрок, а таблица рекордов общая.

## Запуск

Нужен Python 3.10+.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\\Scripts\\activate
pip install -r requirements.txt
python app.py
```

Linux/macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открой `http://127.0.0.1:5000`. Чтобы играть по Wi-Fi, откройте с других устройств `http://ЛОКАЛЬНЫЙ_IP:5000`.

## Консольная версия

```bash
python game.py
```
