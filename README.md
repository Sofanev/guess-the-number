# NUM//HUNT

Ребрендинг классической игры «Угадай число» для игровой сессии в браузере.

## Что нового

- три режима сектора с разными диапазонами, лимитами ходов и таймером;
- streak-побед, XP и уровень игрока;
- подсказки-сканы с чётностью и примерной зоной;
- шкала тепла цели и история выстрелов;
- адаптивный неоновый интерфейс для компьютера и телефона;
- отдельная сессия и статистика для каждого браузера.

## Запуск

Нужен Python 3.10+.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Linux/macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открыть: `http://127.0.0.1:5000`

Для игры по Wi-Fi запустите сервер на одном компьютере и откройте с другого устройства:

```text
http://ЛОКАЛЬНЫЙ_IP:5000
```

## Консольная версия

Старая консольная версия доступна командой:

```bash
python game.py
```
