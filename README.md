# Угадай число

Консольная игра на Python, в которой нужно угадать случайное число.

## Возможности

- три уровня сложности;
- ограниченное количество попыток;
- подсказки: больше или меньше, расстояние до числа и чётность;
- защита от повторного ввода одного и того же числа;
- динамические границы поиска;
- подсчёт очков;
- возможность сыграть несколько раундов подряд.

## Запуск

Установите Python 3.10 или новее, затем выполните:

```bash
python game.py
```

Игра не требует сторонних библиотек.
