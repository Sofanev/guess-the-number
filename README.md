# NUM//HUNT

Сюжетная аркада «Угадай число» для четырёх агентов: Софья, Сергей, Мила и Настя.

## Сюжет

Мир Хранилища разделён на цифровые сектора. В каждом раунде агент проникает в закрытый сектор, читает следы и ищет секретный ключ. В дуэли один игрок становится Хранителем, а другой — Охотником.

## Исправленная база счёта

- поле `hider_points` теперь создаётся и мигрируется корректно;
- победа в соло начисляет очки за попытки, время и сложность;
- поражение начисляет 20 XP;
- Хранитель получает 100 XP за победную защиту ключа;
- streak и общий рейтинг сохраняются в SQLite.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
pip install -r requirements.txt
python app.py
```
