# NUM//HUNT

Игра «Угадай число» с четырьмя игроками и режимами соло и по ходам.

## Счёт

- победа: базовые 100 очков + бонус за оставшиеся попытки (до 40 за попытку) + бонус времени в соло + бонус сложности;
- поражение в соло: 20 очков;
- режим по ходам: угадавший получает обычные очки за победу, при неудаче получает 20 очков;
- если загаданное число никто не угадал, загадавший получает 100 XP за успешную защиту;
- серия побед сбрасывается при поражении.

## Игроки

Софья, Сергей, Мила и Настя. Результаты, XP, победы и поражения сохраняются в SQLite в `instance/numhunt.sqlite3`.

## Режим по ходам

1. Выберите одного игрока как загадчика и другого как отгадывающего.
2. Загадчик вводит секретное число скрыто.
3. Отгадывающий переходит к вводу вариантов.
4. После результата можно начать новый раунд.

## Запуск

```bash
python -m venv .venv
.venv\\Scripts\\activate  # Windows
pip install -r requirements.txt
python app.py
```
